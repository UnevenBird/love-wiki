ByteData:setInt8

From LOVE
Available since LÖVE 12.0
This method is not supported in earlier versions.

Writes one or more numbers as signed 8-bit integers into the ByteData's memory, starting at the given byte offset.

Function

Synopsis

ByteData:setInt8( offset, value, ... )

Arguments

number offset
The offset in bytes from the start of the ByteData's memory.
number value
The first value to write.
number ...
Further values, written one after another.

Returns

Nothing.

Function

Synopsis

ByteData:setInt8( offset, values )

Arguments

number offset
The offset in bytes from the start of the ByteData's memory.
table values
An array of values to write, one after another.

Returns

Nothing.

Notes

Each value takes 1 byte and is written in the native byte order of the system (little-endian on all platforms LÖVE supports). Values outside the range of the type are converted the way a C cast would convert them.

An error is raised if the values do not fit within the ByteData's memory starting at offset.

Examples

Fill a buffer

local data = love.data.newByteData(16)
data:setInt8(0, 1, 2, 3)
data:setInt8(3, {4})
print(data:getInt8(0, 4)) -- 1 2 3 4
