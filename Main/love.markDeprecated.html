love.markDeprecated

From LOVE
Available since LÖVE 12.0
This function is not supported in earlier versions.

Marks an API as deprecated: prints a warning naming it and where it was called from, the same way LÖVE's own deprecated functions do. Useful for libraries.

Function

Synopsis

love.markDeprecated( level, name, apitype, deprecationtype, replacement )

Arguments

number level
The stack level to report as the call site, as in Lua's error: 1 is the function calling markDeprecated, 2 is its caller, and so on.
string name
The name of the deprecated API.
APIType apitype
What kind of API it is.
DeprecationType deprecationtype
Whether it was renamed, replaced, or has no replacement.
string replacement (nil)
The name of the replacement. Required unless deprecationtype is "noreplacement".

Returns

Nothing.

Notes

Each API is reported once. Nothing is printed if deprecation output is disabled with love.setDeprecationOutput.

Examples

Deprecate a library function

function lib.oldName(...)
    love.markDeprecated(2, "lib.oldName", "function", "renamed", "lib.newName")
    return lib.newName(...)
end
