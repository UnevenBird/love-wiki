love.graphics.newComputeShader

From LOVE
Available since LÖVE 12.0
This function is not supported in earlier versions.

Creates a new compute Shader. Compute shaders run general-purpose code on the GPU, outside of drawing; they are started with love.graphics.dispatchThreadgroups or love.graphics.dispatchIndirect, and typically read and write GraphicsBuffers and compute-writable Textures.


This function can be slow if it is called repeatedly, such as from love.update or love.draw. If you need to use a specific resource often, create it once and store it somewhere it can be reused!  



Function

Synopsis

shader = love.graphics.newComputeShader( code, options )

Arguments

string code
The shader code, or a filepath to a file containing it. It must contain a void computemain() function and declare the local threadgroup size with layout(local_size_x = X, local_size_y = Y, local_size_z = Z) in;.
table options (nil)
Optional table of compile options, the same as in love.graphics.newShader:
table defines (nil)
A table of #define names and values to prepend to the code.
string debugname (nil)
A name shown by graphics debugging tools, see Shader:getDebugName.

Returns

Shader shader
The new compute Shader.

Notes

Compute shaders require GLSL 4.30 / GLSL ES 3.10 level hardware: check the glsl4 GraphicsFeature with love.graphics.getSupported. The size limits for dispatches are reported by love.graphics.getSystemLimits (threadgroupsx, threadgroupsy, threadgroupsz).

Examples

Double every number in a buffer

local buffer = love.graphics.newBuffer("float", 1024, {shaderstorage = true})

local shader = love.graphics.newComputeShader([[
layout(local_size_x = 64) in;
layout(std430) buffer Numbers { float values[]; };

void computemain()
{
    uint i = love_GlobalThreadID.x;
    if (i < values.length())
        values[i] *= 2.0;
}
]])
shader:send("Numbers", buffer)

local x = shader:getLocalThreadgroupSize()
love.graphics.dispatchThreadgroups(shader, math.ceil(1024 / x))
