love.graphics.replaceTransform

From LOVE
Available since LÖVE 11.0
This function is not supported in earlier versions.

Replaces the current coordinate transformation with the given Transform object.

Function

Synopsis

love.graphics.replaceTransform( transform )

Arguments

Transform transform
The Transform object to replace the current graphics coordinate transform with.

Returns

Nothing.

Function

Available since LÖVE 12.0
This variant is not supported in earlier versions.

Synopsis

love.graphics.replaceTransform( x, y, angle, sx, sy, ox, oy, kx, ky )

Arguments

number x (0)
The position on the x-axis.
number y (0)
The position on the y-axis.
number angle (0)
Orientation (radians).
number sx (1)
Scale factor (x-axis).
number sy (sx)
Scale factor (y-axis).
number ox (0)
Origin offset (x-axis).
number oy (0)
Origin offset (y-axis).
number kx (0)
Shearing factor (x-axis).
number ky (0)
Shearing factor (y-axis).

Returns

Nothing.

Examples

local transform = love.math.newTransform()
transform:translate(200, 0)

function love.draw()
    love.graphics.translate(100, 100)
    love.graphics.rectangle("fill", 0, 0, 50, 50)

    love.graphics.replaceTransform(transform)
    love.graphics.rectangle("fill", 0, 0, 50, 50)
end
