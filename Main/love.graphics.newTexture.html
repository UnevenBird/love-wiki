love.graphics.newTexture

From LOVE
Available since LÖVE 12.0
This function is not supported in earlier versions.

Creates a new Texture: an image that can be drawn, rendered to, sampled in shaders or written by compute shaders, depending on its settings. love.graphics.newImage and love.graphics.newCanvas are convenience functions that create Textures with fitting settings.


This function can be slow if it is called repeatedly, such as from love.update or love.draw. If you need to use a specific resource often, create it once and store it somewhere it can be reused!  



Function

Creates a 2D texture from an image.

Synopsis

texture = love.graphics.newTexture( filename, settings )

Arguments

string filename
A filepath to an image file, or a File, FileData, ImageData or CompressedImageData object.
table settings (nil)
Optional table of settings to configure the texture, containing the following fields:
PixelFormat format (normal)
The format of the texture, for textures created without image data. For textures created from images the format comes from the image.
boolean canvas (false)
Whether the texture can be rendered to (set with love.graphics.setCanvas).
boolean computewrite (false)
Whether a compute shader can write to the texture, as an image2D-style uniform.
boolean mipmaps (false)
Whether the texture has mipmaps (a boolean or a MipmapMode): true or "auto" generates them automatically (from image data, and after rendering to a canvas), "manual" requires Texture:generateMipmaps.
number mipmapcount (all)
The number of mipmap levels, if mipmaps are used. Fewer than the full chain is allowed.
boolean linear (false)
True to treat the pixels as linear instead of sRGB, when gamma correct rendering is enabled.
number msaa (0)
The number of MSAA samples, for canvases.
number dpiscale (1)
The DPI scale used when drawing the texture and in Texture:getWidth/Texture:getHeight. For images loaded from files with an @2x-style suffix, the scale is taken from the file name.
table viewformats (nil)
An array of PixelFormats that texture views of this texture may use, in addition to its own format.
boolean readable (nil)
Whether the texture can be sampled in shaders. Defaults to true, except for depth/stencil canvases.
string debugname (nil)
A name shown by graphics debugging tools, see Texture:getDebugName.

Returns

Texture texture
The new Texture.

Function

Creates an empty array or volume texture.

Synopsis

texture = love.graphics.newTexture( width, height, layers, settings )

Arguments

number width
The width of the texture in pixels.
number height
The height of the texture in pixels.
number layers
The number of layers.
table settings (nil)
Optional table of settings to configure the texture, containing the following fields:
TextureType type ("array")
The type of the texture: "array" or "volume".
PixelFormat format (normal)
The format of the texture, for textures created without image data. For textures created from images the format comes from the image.
boolean canvas (false)
Whether the texture can be rendered to (set with love.graphics.setCanvas).
boolean computewrite (false)
Whether a compute shader can write to the texture, as an image2D-style uniform.
boolean mipmaps (false)
Whether the texture has mipmaps (a boolean or a MipmapMode): true or "auto" generates them automatically (from image data, and after rendering to a canvas), "manual" requires Texture:generateMipmaps.
number mipmapcount (all)
The number of mipmap levels, if mipmaps are used. Fewer than the full chain is allowed.
boolean linear (false)
True to treat the pixels as linear instead of sRGB, when gamma correct rendering is enabled.
number msaa (0)
The number of MSAA samples, for canvases.
number dpiscale (1)
The DPI scale used when drawing the texture and in Texture:getWidth/Texture:getHeight. For images loaded from files with an @2x-style suffix, the scale is taken from the file name.
table viewformats (nil)
An array of PixelFormats that texture views of this texture may use, in addition to its own format.
boolean readable (nil)
Whether the texture can be sampled in shaders. Defaults to true, except for depth/stencil canvases.
string debugname (nil)
A name shown by graphics debugging tools, see Texture:getDebugName.

Returns

Texture texture
The new Texture.

Notes

An empty texture that is neither a canvas nor compute-writable has undefined contents until it's filled.

Use love.graphics.getTextureFormats to check which pixel formats can be used as canvases, with linear filtering, or with computewrite.

Examples

A render target that compute shaders can also write to

local target = love.graphics.newTexture(512, 512, {
    canvas = true,
    computewrite = true,
    format = "rgba8",
    debugname = "Post-process target",
})

A texture from an image with mipmaps

local grass = love.graphics.newTexture("grass.png", {mipmaps = true})
grass:setMipmapFilter("linear")
