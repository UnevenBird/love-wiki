Data:getUInt16

From LOVE
Available since LÖVE 12.0
This method is not supported in earlier versions.

Reads one or more values stored as unsigned 16-bit integers at the given byte offset in the Data's memory.

Function

Synopsis

value, ... = Data:getUInt16( offset, count )

Arguments

number offset
The offset in bytes from the start of the Data's memory.
number count (1)
The number of consecutive values to read.

Returns

number value
The first value, read as an unsigned 16-bit integer.
number ...
Further values, if count is greater than 1.

Notes

Each value takes 2 bytes. Values are read in the native byte order of the system (little-endian on all platforms LÖVE supports).

An error is raised if count is less than 1, or if offset and count reach outside the Data's memory.

Examples

Read a header

local data = love.filesystem.newFileData("level.bin")
local version = data:getUInt8(0)
local w, h = data:getUInt16(4, 2)
