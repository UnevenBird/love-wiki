love.graphics.newBuffer

From LOVE
Available since LÖVE 12.0
This function is not supported in earlier versions.

Creates a new GraphicsBuffer: an array of elements in graphics memory, usable as vertex data for Meshes, vertex indices, texel data or shader storage data in Shaders, or arguments of indirect draws and dispatches.


This function can be slow if it is called repeatedly, such as from love.update or love.draw. If you need to use a specific resource often, create it once and store it somewhere it can be reused!  



Function

Synopsis

buffer = love.graphics.newBuffer( format, size, settings )

Arguments

BufferDataFormat format
The format of every element, as a single BufferDataFormat string.
number size
The number of elements. The buffer is filled with zeros.
table settings
A table of settings:
boolean vertex (false)
Whether the buffer can be used for vertex attributes of a Mesh.
boolean index (false)
Whether the buffer can be used as an index buffer (format uint16 or uint32).
boolean texel (false)
Whether the buffer can be accessed in shaders as a texel buffer (samplerBuffer).
boolean shaderstorage (false)
Whether the buffer can be bound to a shader storage block in shaders.
boolean indirectarguments (false)
Whether the buffer can hold arguments for love.graphics.drawIndirect, love.graphics.drawFromShaderIndirect and love.graphics.dispatchIndirect.
BufferDataUsage usage ("dynamic")
How often the contents are expected to change.
string debugname (nil)
A name shown by graphics debugging tools, see GraphicsBuffer:getDebugName.

Returns

GraphicsBuffer buffer
The new buffer.

Function

Creates a buffer whose elements have several fields (a struct).

Synopsis

buffer = love.graphics.newBuffer( format, size, settings )

Arguments

table format
An array of field declarations describing one element, each a table with:
BufferDataFormat format
The data format of the field.
string name (nil)
The name of the field.
number location (nil)
The vertex attribute location of the field. Required for vertex buffers; it must match a layout (location = #) input in the vertex shader.
number arraylength (0)
The array length, for fields of shader storage blocks that are arrays.
number size
The number of elements.
table settings
A table of settings, as in the first variant.

Returns

GraphicsBuffer buffer
The new buffer.

Function

Creates a buffer with initial contents from a table.

Synopsis

buffer = love.graphics.newBuffer( format, data, settings )

Arguments

table format
A single BufferDataFormat string or a table of field declarations, as above.
table data
The initial contents: a table of tables (one per element, with its components in order), or a flat table with all components one after another. The number of elements comes from the table.
table settings
A table of settings, as in the first variant.

Returns

GraphicsBuffer buffer
The new buffer.

Function

Creates a buffer with initial contents from a Data object.

Synopsis

buffer = love.graphics.newBuffer( format, data, settings )

Arguments

table format
A single BufferDataFormat string or a table of field declarations, as above.
Data data
The initial contents as raw bytes, laid out like the buffer's elements.
table settings
A table of settings, as in the first variant.

Returns

GraphicsBuffer buffer
The new buffer.

Notes

Not every BufferDataFormat can be used with every kind of buffer, and texel buffers need the texelbuffer GraphicsFeature. The format of a shader storage block in a shader can be queried with Shader:getBufferFormat.

Examples

Per-instance positions for instanced drawing

local format = {{name = "InstancePosition", format = "floatvec2", location = 3}}
local positions = {}
for i = 1, 100 do positions[i] = {math.random(0, 800), math.random(0, 600)} end

local instances = love.graphics.newBuffer(format, positions, {vertex = true})
mesh:attachAttribute(3, instances, "perinstance")
love.graphics.drawInstanced(mesh, 100)

A shader storage buffer for a compute shader

local particles = love.graphics.newBuffer(shader:getBufferFormat("Particles"), 4096, {shaderstorage = true})
shader:send("Particles", particles)
