Function

Available since LÖVE 12.0
This variant is not supported in earlier versions.

Synopsis

rasterizer = love.font.newRasterizer( filename, size, settings )

Arguments

string filename
Path to a TrueType font file, or a FileData containing it.
number size (12)
The font size.
table settings
A table of settings:
HintingMode hinting ("normal")
True Type hinting mode.
number dpiscale (dpi scale)
The DPI scale factor of the font.
boolean sdf (false)
Whether the glyphs are rendered as signed distance fields, for sharp text at any scale (requires a matching shader).

Returns

Rasterizer rasterizer
The rasterizer.
