love.graphics.readbackBufferAsync

From LOVE
Available since LÖVE 12.0
This function is not supported in earlier versions.

Starts copying the contents of a GraphicsBuffer into ByteData without waiting for the GPU.

Function

Synopsis

readback = love.graphics.readbackBufferAsync( buffer, offset, size, dest, destoffset )

Arguments

GraphicsBuffer buffer
The buffer to read from.
number offset (0)
The offset in bytes from the start of the buffer.
number size (all)
The number of bytes to read. Defaults to everything after the offset.
ByteData dest (nil)
An existing ByteData to fill instead of creating a new one.
number destoffset (0)
The offset in bytes into dest.

Returns

GraphicsReadback readback
The pending readback. GraphicsReadback:getBufferData returns the data once it completes.

Notes

The returned GraphicsReadback completes some time later (usually after a frame or more). It is updated automatically when the frame is presented; poll it with GraphicsReadback:isComplete or block with GraphicsReadback:wait.

Examples

Read results of a compute shader without stalling

local pending

function love.update()
    if not pending then
        love.graphics.dispatchThreadgroups(shader, 16)
        pending = love.graphics.readbackBufferAsync(buffer)
    elseif pending:isComplete() then
        local data = pending:getBufferData()
        print(data:getFloat(0, 4))
        pending = nil
    end
end
