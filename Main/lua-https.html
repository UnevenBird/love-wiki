lua-https

From LOVE
Available since LÖVE 12.0
This module is not supported in earlier versions.

lua-https is a small HTTPS client library that comes included with LÖVE. It uses the system's own networking and TLS implementation (WinINet on Windows, NSURLSession on macOS and iOS, the Java networking API on Android, libcurl on Linux), so no certificates or TLS libraries have to be bundled with the game.

It is loaded with require; it is not part of the love table: 

local https = require("https")

Requests are blocking: https.request returns when the response has arrived. Use a thread to keep the game responsive while a request runs.

Functions

Function Description
https.request Sends an HTTP or HTTPS request and returns the response.

Examples

Fetch a file

local https = require("https")
local code, body = https.request("https://love2d.org/")
print(code, #body)

Request from a thread

-- main.lua
local thread = love.thread.newThread([[
    local https = require("https")
    local url = ...
    local code, body = https.request(url)
    love.thread.getChannel("https"):push({code = code, body = body})
]])
thread:start("https://example.com/data.json")

function love.update()
    local result = love.thread.getChannel("https"):pop()
    if result then print(result.code, result.body) end
end
