love.graphics.drawFromShader

From LOVE
Available since LÖVE 12.0
This function is not supported in earlier versions.

Draws primitives whose vertex positions are computed entirely in the vertex shader, without a Mesh or vertex buffer. The shader typically uses love_VertexID and love_InstanceID and reads data from GraphicsBuffers or textures.

Function

Synopsis

love.graphics.drawFromShader( primitivetype, vertexcount, instancecount, texture )

Arguments

MeshDrawMode primitivetype
How the generated vertices form primitives: "triangles", "strip", "fan" or "points".
number vertexcount
The number of vertices to generate.
number instancecount (1)
The number of instances to draw.
Texture texture (nil)
An optional texture used as the shader's main texture (MainTex).

Returns

Nothing.

Function

Draws triangles using vertex indices from an index buffer.

Synopsis

love.graphics.drawFromShader( indexbuffer, indexcount, instancecount, startindex, texture )

Arguments

GraphicsBuffer indexbuffer
A buffer created with the index usage flag.
number indexcount
The number of indices to use.
number instancecount (1)
The number of instances to draw.
number startindex (1)
The first index in the buffer to use.
Texture texture (nil)
An optional texture used as the shader's main texture (MainTex).

Returns

Nothing.

Notes

A custom Shader must be active. The current color and transformation are available to the shader as usual. With the "fan" mode at most 65535 vertices can be drawn.

Examples

A full-screen triangle

local shader = love.graphics.newShader([[
vec4 position(mat4 transform, vec4 vertex)
{
    vec2 uv = vec2((love_VertexID << 1) & 2, love_VertexID & 2);
    return vec4(uv * 2.0 - 1.0, 0.0, 1.0);
}
]])

function love.draw()
    love.graphics.setShader(shader)
    love.graphics.drawFromShader("triangles", 3)
    love.graphics.setShader()
end
