CompressedImageData:isLinear

From LOVE
Available since LÖVE 12.0
This method is not supported in earlier versions.

Gets whether the CompressedImageData's pixels are treated as linear instead of sRGB when a Texture is created from it.

Function

Synopsis

linear = CompressedImageData:isLinear( )

Arguments

None.

Returns

boolean linear
True for linear color values, false for sRGB.
