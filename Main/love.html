love

From LOVE

When writing games using LÖVE, the most important part of the API are the callbacks: love.load is for setting up the game state, love.update is for updating that state, and love.draw is for drawing the state to the screen.

Games may override additional callbacks in order to handle input from the user, handle errors, and more.

LÖVE provides blank placeholders for these callbacks, which you can override inside your own code by creating your own function with the same name as the callback: 

-- Load some default values for our rectangle.
function love.load()
    x, y, w, h = 20, 20, 60, 20
end

-- Increase the size of the rectangle every frame.
function love.update(dt)
    w = w + 1
    h = h + 1
end

-- Draw a coloured rectangle.
function love.draw()
    -- In versions prior to 11.0, color component values are (0, 102, 102)
    love.graphics.setColor(0, 0.4, 0.4)
    love.graphics.rectangle("fill", x, y, w, h)
end
