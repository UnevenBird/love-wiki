love.physics.computeLinearStiffness

From LOVE
Available since LÖVE 12.0
This function is not supported in earlier versions.

Computes stiffness and damping values for a linear spring from an oscillation frequency and damping ratio, using the masses of the given bodies.

Function

Synopsis

stiffness, damping = love.physics.computeLinearStiffness( frequency, dampingratio, body1, body2 )

Arguments

number frequency
The oscillation frequency of the spring in Hertz.
number dampingratio
The damping ratio: 0 means no damping, 1 is critical damping.
Body body1
The first body attached to the joint.
Body body2 (nil)
The second body attached to the joint. If nil, the World's static ground body is used.

Returns

number stiffness
The stiffness, as used by the joints' setStiffness methods.
number damping
The damping coefficient, as used by the joints' setDamping methods.

Notes

Box2D 2.4 joints are configured with stiffness and damping instead of the frequency and damping ratio used by LÖVE 11 and earlier. These functions convert between the two. When both bodies have mass, their combined mass is used; static bodies count as infinitely heavy.

Examples

Configure a joint the LÖVE 11 way

-- LÖVE 11: joint:setFrequency(4); joint:setDampingRatio(0.5)
local k, d = love.physics.computeLinearStiffness(4, 0.5, bodyA, bodyB)
joint:setStiffness(k)
joint:setDamping(d)
