GraphicsBuffer:setArrayData

From LOVE
Available since LÖVE 12.0
This method is not supported in earlier versions.

Replaces the contents of the buffer, or a range of its array elements, with values from a table or a Data object.

Function

Synopsis

GraphicsBuffer:setArrayData( data, sourcestart, deststart, count )

Arguments

table data
The values. Either a table of tables, one per array element, each containing the element's components in the order of the buffer's format; or a flat table with all components of all elements one after another.
number sourcestart (1)
The first element of data to use.
number deststart (1)
The first array element of the buffer to replace.
number count (all)
The number of array elements to replace.

Returns

Nothing.

Function

Synopsis

GraphicsBuffer:setArrayData( data, sourcestart, deststart, count )

Arguments

Data data
Raw bytes laid out like the buffer's elements (see GraphicsBuffer:getFormat); indices are counted in units of the buffer's array stride.
number sourcestart (1)
The first element of data to use.
number deststart (1)
The first array element of the buffer to replace.
number count (all)
The number of array elements to replace.

Returns

Nothing.

Notes

Buffers created with the "static" BufferDataUsage can still be updated, but updating them often is slower than with "dynamic" or "stream".

Examples

Upload particle positions

local buffer = love.graphics.newBuffer({{name = "pos", format = "floatvec2"}}, 3, {shaderstorage = true})
buffer:setArrayData({ {0, 0}, {10, 0}, {0, 10} })
-- or, flat:
buffer:setArrayData({ 0, 0, 10, 0, 0, 10 })
